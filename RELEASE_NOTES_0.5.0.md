# ForgeGuard Nexus 5.0 — Competition Release 0.5.0

## Major changes

- Reframed the product as a complete Industrial AI Agent Platform.
- Added persistent cross-platform SQLite/PostgreSQL repository.
- Added Human Safety, Sustainability and Resilience Agents.
- Added governed local-first industrial Copilot.
- Added multi-objective decision arena and explicit safety invariants.
- Added asset, incident, work-order, sustainability, edge fleet, Agent runtime and governance product surfaces.
- Added Windows, Arch/Debian and Jetson deployment paths.
- Added TensorRT, ONNX Runtime and NumPy fallback inference contracts.
- Added 18 automated backend tests and browser workflow QA.

## Honest boundaries

- The bundled HGB model remains a reproducible CPU baseline.
- TensorRT support is a runtime contract and tested toolchain; a validated neural engine is not bundled as a factory-proven model.
- Public, synthetic, replay and physical evidence must be reported separately.
