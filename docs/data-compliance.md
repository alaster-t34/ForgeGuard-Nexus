# Data, privacy, intellectual-property, and safety statement

## Demo data

The default demonstration uses synthetic asset, telemetry, inventory, production, and work-order data. It is intended to validate workflow behavior, not model accuracy in a specific factory.

## Real data onboarding

A real deployment must record data owner, authorization, retention period, permitted uses, geographic restrictions, and deletion process. Personally identifiable information is not required for the core workflow. Operator identity should be minimized to an auditable enterprise identifier.

## Existing model and dataset disclosure

All model weights, datasets, manuals, and code inherited from prior project work must be listed with provenance and license. Placement inside this repository does not establish ownership. The default repository does not redistribute the uploaded weight files.

## Industrial safety boundary

ForgeGuard is decision support. Equipment-control integrations are read-only by default. A production stop, continued operation under risk, work-order release, and post-maintenance return to service require authorized personnel and enterprise procedures.
