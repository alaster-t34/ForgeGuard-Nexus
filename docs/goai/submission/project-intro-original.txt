项目名称：ForgeGuard Nexus 5.0——证据驱动的工业运维与供应链协同 Agent。项目面向设备维护人员、可靠性工程师、生产管理人员及供应链协调人员，解决工业现场传感器、报警、维修手册、历史工单、备件库存和生产计划等信息分散，故障诊断与维修、备件及排产决策脱节，结果难追溯的问题。系统以旋转机械和关键工业资产为主要对象，通过多智能体协同完成数据质量门控、异常识别、故障诊断、剩余寿命与安全风险评估，并结合人员技能、备件库存、供应周期和生产约束生成可解释的维修方案；方案经人工审批后形成工单，再利用维修后数据验证恢复，构成“发现—分析—决策—执行—复测”的闭环。创新点在于将证据驱动的多 Agent 协作与确定性安全门控结合，对低质量或冲突证据主动拒识，并从安全、停机、成本、库存与供应风险等维度比较方案，不直接控制真实设备。项目采用 Apache-2.0 许可，计划开放 Agent 契约、场景模板、示例数据和部署文档。目前已完成 Windows 可运行版本、实时与 CSV 分析、25 个模拟工业场景、审计日志及基础评测，可进行完整 Demo 演示，并支持跨平台部署与复现。
