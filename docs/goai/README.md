This directory collects the competition-facing material for **GOAI Boundless Agents - AI + Industrial Manufacturing**.

- `GOAI_SUBMISSION_ZH.md` - compact project narrative, task loop, architecture, evidence and boundaries.
- `DEMO_SCRIPT_2MIN_ZH.md` - 2-minute hero demo storyboard.
- `SUBMISSION_CHECKLIST_ZH.md` - final preliminary-submission checklist.
- `submission/project-intro-500zh.txt` - 500-character-safe project introduction draft.
- `submission/ForgeGuard_Nexus_5.0_GOAI_Preliminary.pdf` - existing preliminary proposal PDF.

## Recommended presentation order

1. Real maintenance decision problem.
2. One complete task loop.
3. Evidence/Agent/tool architecture.
4. Human-governed decision and work order.
5. Post-maintenance verification.
6. Failure handling.
7. Benchmark and engineering evidence with limitations.
8. Open reuse and deployment paths.
