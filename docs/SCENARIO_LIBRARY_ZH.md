# 工业场景库说明

工业场景库用于验证 ForgeGuard 的多智能体业务闭环，不用于替代实时传感器和 CSV 数据分析。所有场景的 `simulation_only` 均为 `true`。

## 轴承与旋转机械

| 场景 | 主要证据 | 典型处置方向 |
|---|---|---|
| 轴承外圈剥落 | 周期性冲击、包络峰、局部表面缺陷 | 受控停机、轴承更换、维修后复测 |
| 轴承内圈故障 | 随转速调制冲击、温升 | 检查配合与载荷、计划更换 |
| 滚动体故障 | 滚动体通过频率与冲击 | 复核润滑、游隙与表面损伤 |
| 润滑失效 | 高频能量、温升、摩擦迹象 | 确认润滑剂、补充或更换 |
| 轴系不对中 | 1X/2X 分量、轴向振动 | 对中、软脚与联轴器检查 |
| 转子不平衡 | 稳定 1X 径向分量 | 动平衡与积灰检查 |
| 机械松动 | 宽带谐波和间歇冲击 | 紧固件、基础和配合检查 |
| 轴弯曲 | 1X/2X 与相位异常 | 测量跳动、评估更换 |
| 结构共振 | 窄频放大、转速敏感 | 改变工况、加固或避开共振区 |

## 齿轮箱与传动

| 场景 | 主要证据 | 典型处置方向 |
|---|---|---|
| 齿轮齿面损伤 | 啮合频率边带与冲击 | 检查齿面、润滑和载荷 |
| 皮带打滑 | 转速差、温升和低频波动 | 调整张力、检查皮带与轮槽 |

## 泵风机与流体设备

| 场景 | 主要证据 | 典型处置方向 |
|---|---|---|
| 泵汽蚀 | 高频宽带噪声、吸入口压力低、流量波动 | 恢复 NPSH、检查阀门和液位 |
| 密封泄漏 | 泄漏观测、压力衰减 | 隔离设备、检查密封与轴套 |
| 风机叶片积灰 | 不平衡、能耗上升、视觉沉积 | 清洁叶片并重新平衡 |

## 电机与电气

| 场景 | 主要证据 | 典型处置方向 |
|---|---|---|
| 电机轴承过热 | 温升、振动与电流负荷 | 检查轴承、润滑和负载 |
| 三相电流不平衡 | 负序电流、温升、转矩波动 | 检查电源、端子和绕组 |

## 能源与环境

| 场景 | 主要证据 | 典型处置方向 |
|---|---|---|
| 能源漂移 | 单位负荷能耗持续偏离基线 | 检查摩擦、工况与控制参数 |
| 冷却效率下降 | 温差、能耗和换热能力下降 | 清洗换热器、检查流量与制冷系统 |
| 压缩空气泄漏 | 非生产时段流量和能耗异常 | 分区定位、修复接头与阀件 |

## 数据质量与治理

| 场景 | 主要证据 | 典型处置方向 |
|---|---|---|
| 跨模态证据冲突 | 振动与视觉结论不一致 | 主动补采、人工复核，不直接维修 |
| 传感器安装异常 | 安装松动、方向或灵敏度异常 | 重新安装、校准并建立新基线 |
| 采样丢包 | 序列缺失、时间戳异常 | 检查网络、网关、缓存与重传 |

## 生产与韧性

| 场景 | 主要证据 | 典型处置方向 |
|---|---|---|
| 备件供应受限 | 库存不足、交期过长 | 降载、替代件、排产与供应协调 |
| 维修人员不足 | 合格技能人员不可用 | 延迟高风险作业、跨班组协调 |
| 生产负荷过载 | 计划负荷超出设备健康边界 | 调整排产、切换备用资产或降低负载 |

## 使用原则

1. 场景库用于验证软件逻辑和演示；
2. 真实诊断应使用实时采集或 CSV；
3. 场景结论不能用于真实设备安全决策；
4. 所有高风险方案仍受人工审批门控；
5. 维修后验证仍是关闭事件的必要条件。
