# ForgeGuard Nexus 5.0 用户说明书

本说明书面向设备维护人员、可靠性工程师、班组长和演示人员，不要求读者理解 Agent、RUL 或边缘计算内部实现。

## 1. 先分清三种入口

### 实时检测

用于真实传感器、采集卡、Jetson、串口设备或 HTTP 网关持续传输数据。系统连续更新波形、数据质量和故障判断。

### CSV 文件分析

用于已有历史数据、公开数据集、台架或现场导出的 CSV。系统一次性读取文件并按窗口生成报告。

### 工业场景库

用于演示 25 种故障、数据质量、能源和生产约束下的 Agent 闭环。它不是真实现场数据。

## 2. 任务 A：用内置演示测试实时检测

1. 打开“数据检测与分析”；
2. 选择“实时检测”；
3. 数据来源选择“内置实时演示”；
4. 选择设备并填写采样率、转速和负载；
5. 点击“开始实时检测”；
6. 观察实时波形、数据质量、当前判断和异常概率；
7. 切换故障或采集异常类型；
8. 点击“停止检测”。

内置演示只用于测试软件链路，不能作为物理实验结果。

## 3. 任务 B：连接真实采集设备

1. 创建实时任务，数据来源选择“外部传感器/网关”；
2. 记下会话 ID 和帧接口；
3. 使用 `stream-live-serial`、`stream-live-csv` 或自有 HTTP 客户端上传；
4. 每帧建议 2048 或 4096 点；
5. 记录设备、传感器、安装位置、采样率、量程和校准信息；
6. 观察数据质量是否通过，不能绕过质量拒识直接采用故障结果。

## 4. 任务 C：分析已有 CSV

1. 进入“数据检测与分析”；
2. 切换到“CSV 文件分析”；
3. 选择文件；
4. 选择设备；
5. 填写真实采样率、转速和负载；
6. 多列文件填写信号列名或列号，不确定时留空自动识别；
7. 设置窗口长度和步长；
8. 点击“开始分析”；
9. 查看有效窗口、拒绝窗口、主导类别、异常概率和告警编号；
10. 在 `runtime-data/analysis-reports/` 查看 JSON 报告。

## 5. 任务 D：运行工业场景库

1. 点击左侧“工业场景库”；
2. 使用搜索框查找设备、故障、模态或业务条件；
3. 使用分类按钮筛选；
4. 点击场景卡的“选择”或“运行”；
5. 观察 Agent 如何完成诊断、RUL、安全、能耗、韧性和维修规划；
6. 进入维修决策审批方案；
7. 创建工单并执行维修后验证。

当前共有 25 个场景，包括轴承、齿轮、泵、风机、电机、电气、能源、数据质量、备件、人员和生产负荷。

## 6. 任务 E：从总览进入全部告警

运行总览右侧“最近工业事件”标题栏有“全部”。点击后进入完整告警事件页面。

若当前没有事件，页面会显示“暂无事件”。先运行一个场景，或让实时/CSV 分析创建告警。

## 7. 任务 F：使用顶部搜索

- 鼠标点击右上角搜索框；
- 或按 `Ctrl+K`；
- 输入设备、告警、工单、页面或场景关键词；
- 使用方向键切换；
- 按 Enter 打开；
- 按 Esc 关闭。

例如输入“汽蚀”，可直接打开“泵汽蚀”场景。

## 8. 任务 G：完成维修闭环

1. 在告警事件中查看诊断与证据；
2. 在维修决策中比较安全、韧性、环境、停机和成本；
3. 授权人员批准选中方案；
4. 在工单执行中完成安全检查和步骤；
5. 上传维修后数据或执行演示复测；
6. 验证通过后关闭；未通过则自动重开。

## 9. 关键术语

- **数据质量门控**：判断输入是否可信，避免把采集故障误认为设备故障；
- **RUL**：剩余可用寿命估计，应理解为区间而不是保证；
- **AI 智能体**：有明确职责、结构化输出和工具权限的任务模块；
- **边缘设备**：现场 Jetson、工业 PC 或采集网关；
- **多模态**：振动、视觉、温度、电流、日志等不同证据；
- **韧性**：系统在故障、断网、缺件或人员不足时维持和恢复工作的能力；
- **人机共治**：AI 提供证据和方案，人保留高风险决策权。

## 10. 数据真实性说明

界面必须区分：模拟数据、公开数据集、历史现场数据、真实台架数据和真实现场连续数据。场景库属于模拟数据；不得将其宣传为真实工厂验证结果。
