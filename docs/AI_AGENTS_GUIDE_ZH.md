# AI 智能体工作台说明

## 为什么旧版点击没有反应

0.7.1 的“AI 智能体”页面只渲染状态卡片，卡片、流程阶段、工具和模型没有绑定交互事件，也没有详情视图。它本质上是只读监控面板，不是用户操作错误。

## 0.7.8 完整软件包可以做什么

- 点击 13 个智能体卡片或流程阶段；
- 查看职责、输入、输出和治理边界；
- 查看来自真实事件 `trace` 与 `tool_calls` 的执行记录；
- 点击执行记录跳转到关联告警事件；
- 查看每个智能体的工具权限和高风险审批要求；
- 点击工具和模型查看运行说明；
- 搜索智能体并按运行状态筛选；
- 带当前智能体上下文打开 ForgeGuard Copilot；
- 进入场景库运行完整、受治理的多智能体闭环。

## 为什么不能单独点一个智能体直接控制设备

专业智能体只承担一个职责。生产变更、工单下发和设备控制必须经过协调器状态机、证据门控、人员安全检查和授权审批。单智能体不能绕过这些环节，这是产品安全边界。
